# Task 16 – Simple Profit Analysis

## 📊 Overview

This project focuses on analyzing profit across different product categories using a Superstore-style retail dataset.

## 🎯 Objective

Compare total profit across product categories and understand basic profitability.

## 🛠️ Tools Used

- Microsoft Excel
- Data Analysis
- Data Aggregation
- Data Visualization

## 🔍 Analysis Performed

- Grouped data by product category
- Calculated total sales
- Calculated total profit
- Calculated average profit
- Calculated profit margin
- Compared category-wise profitability
- Created a bar chart for profit comparison

## 💡 Key Learning

Revenue and profit are different measures. High sales do not necessarily mean high profit because discounts, product costs, and product mix can affect profitability.

## 📂 Project Files

- `superstore_profit_data.csv` – Dataset
- `Task_16_Simple_Profit_Analysis.xlsx` – Excel analysis
- `Task_16_Profit_Analysis_Report.pdf` – Project report
- `profit_by_category.png` – Visualization

## 📈 Outcome

The project provides a simple category-wise view of profitability and demonstrates how Excel can be used for basic business analysis.
